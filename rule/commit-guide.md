# 提交评论指南

> 提交信息以 `type` 前缀开头，type 从下表选取。

| 类型     | 含义                                   |
| -------- | -------------------------------------- |
| build    | 变更程序构建                           |
| chore    | 不涉及代码的变更，例如变更 CHANGELOG、NOTE |
| ci       | 变更 CI 配置或脚本（如 .gitea/workflows、.github/workflows） |
| cmnt     | 仅变更注释                             |
| docs     | 仅变更文档                             |
| feat     | 新特性                                 |
| fix      | 修复 BUG                               |
| opt      | 编码优化                               |
| perf     | 性能优化                               |
| refactor | 代码重构，但不影响业务功能             |
| revert   | 还原之前的提交                         |
| style    | 编码风格调整，例如格式化               |
| test     | 添加单元测试或集成测试                 |
