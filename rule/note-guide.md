# 注释指南

> **目的**：注释写给下一个读者，不写给编译器——只陈述**代码本身无法表达的信息**，**不含历史记录**，**保持简洁**。

> **对象**：`#` Note（非 docstring）与 Docstring（module / class / function）两类；公共规则两类同守，专有规则各节分述。

## 公共规则

### 追求

追求更高的熵值，以更少的文本承载更多的信息

### 语言

Note 与 Docstring 一律英文。

### 边界

**无状态**：只描述当前代码，不记录「之前如何实现」、不携带设计文档编号——历史在 docs/git 中，重复记录是纯冗余。

**非权威**：注释可能与代码不一致；读实现直接读代码，注释仅辅助理解，不取代读代码。

### 格式

#### 形态
通常为单行或结构化多行
##### 单行
通常为描述句
##### 结构化多行
| 层级               | 记号                        |备注|
| ------------------ | --------------------------- |-----|
| 第 0 级            | 首行描述句                  | 唯一散文|
| 一级               | `-`                         | 作标题须带 `--` 子项；整身扁平弹点列表时 `-` 即一级事实，豁免 |
| 二级               | `--`                        | |
| 三级               | `---`                        | |
| N 级               | `-` × N                    | |
| 参考表             | `===` 下划线（如枚举映射表）| |
| 数据行             | 对齐行 / 矩阵（豁免句点）   | 不挂横线前缀 |

#### 癖好
- 禁句中悬断、禁散文段落

## `#` Note 专有规则

### 存在性判据

**主判据**：这条注释是否陈述了代码本身无法表达的信息？

**回声测试**：遮住注释，只读其下数行代码；若能得到同样信息，则无需写。

**保留白名单**：

| 类别 | 判定                                                                               |
| ---- | ---------------------------------------------------------------------------------- |
| 概括 | 压缩非局部可得的结构（阶段横幅/流程图/归属表）；压缩比：注释跨度 ≪ 被概括代码跨度 |
| 约束 | 不变量、调用顺序、数据语义、并发/性能前提                                          |
| 理由 | 反直觉决策、分支存在的原因、外部 workaround                                        |

**保留不等于免检**：概括类同样受一致性审查约束。

### 位置规则

| 位置                                | 角色   | 默认推定 | 裁决                                                                  |
| ----------------------------------- | ------ | -------- | --------------------------------------------------------------------- |
| 块间（函数头/横幅/流程图/区块边界） | 导航层 | 留       | 内容仍过回声测试；回声横幅按「全域一致」裁决                          |
| 行间（函数体内代码行之间）          | 嫌疑层 | 删       | 例外仅警示类（并发陷阱/非显然约束）→ 压缩 ≤1 行；why 优先上移函数头 |
| 行尾（枚举/常量/表达式末）          | 补注层 | 过主判据 | 非显然才留；数据语义天然通过                                          |

## Docstring 专有规则

### 存在性

- 简单函数可不写
- 名称自明的类（model 层 Input/Output 等）至多一行 docstring

### 格式：单行/Google 风格

**File**：描述（单行或结构化多行）

**Class**：描述（单行或结构化多行）+ 以下详述（可选）：

| 分段 | 含义 | 示例 |
| --- | --- |
| `Attributes:` | 公开实例属性 | `eggs: An integer count of the eggs we have laid.` |

- dataclass 至多一行 docstring，无需 `Attributes:`
- 构造参数写在 `__init__` 的 docstring，不写在类 docstring

**Function**：描述（单行或结构化多行） + 以下分段（可选）：

| 分段         | 含义           | 示例                                                           |
| ------------ | -------------- | -------------------------------------------------------------- |
| `Args:`    | 输入参数       | `temperature: Temperature value for scaling.`                |
| `Returns:` | 返回值         | `Probability distribution after temperature-scaled softmax.` |
| `Raises:`  | 可能抛出的异常 | `ValueError: If temperature <= 0.`                           |

### 书写癖好

**多行起笔换行**：多行 docstring 的开引号 `"""` 后先换行再写内容，首行内容不与开引号同行；单行不受影响。
